# RSS News Bot

Телеграмм бот, который собирает новости из RSS лент. Каждый пользователь подписывается на свои ленты и получает свежие записи.

## Задача 2:

**Цель:** Добавить команды: /add \<url>, /remove \<url>, /list, /latest \<url>, /pagesize \<n>. Сделать так, чтобы бот вёл отдельные диалоги с разными пользователями, а хранение данных было отдельно от логики бота.

Чтение ленты вынесено в отдельный класс, тесты работают на локальных XML-файлах без интернета. Команда /latest показывает новости страницами: бот выводит первую страницу и кнопку "Показать ещё", по нажатию показывается следующая. Команда /pagesize задаёт размер страницы (по умолчанию 3). Размер страницы и текущая позиция чтения хранятся отдельно для каждого пользователя.

### Примеры:

#### Пример 1. Обычная работа

П: /add https://habr.com/rss

Б: Лента добавлена

П: /list

Б: 1. https://habr.com/rss

П: /remove https://habr.com/rss

Б: Лента удалена

#### Пример 2. Два пользователя

П1: /add https://habr.com/rss

Б: Лента добавлена

П2: /list

Б: Подписок пока нет. Добавь ленту командой /add \<url>

#### Пример 3. Ошибки

П: /add

Б: Укажите ссылку: /add \<url>

П: /add habr

Б: Не удалось найти рассылку

П: /add https://habr.com/rss

Б: Лента добавлена

П: /add https://habr.com/rss

Б: Эта лента уже есть в списке

#### Пример 4. Новости по страницам

П: /latest https://habr.com/rss

Б: 1. Вышла новая версия Java — https://habr.com/...

2. Как устроен RSS — https://habr.com/...
3. Telegram-боты на Java — https://habr.com/...

[Показать ещё]

П: (нажимает «Показать ещё»)

Б: 4. Паттерны проектирования — https://habr.com/...

5. Тестирование в JUnit — https://habr.com/...
6. Работа с XML — https://habr.com/...

[Показать ещё]

(когда новости закончились)

Б: Больше новостей нет

#### Пример 5. Размер страницы

П: /pagesize 2

Б: Размер страницы изменён: 2

П: /pagesize 0

Б: Размер страницы должен быть числом от 1 до 20

## Задача 3. Пошаговое добавление ленты

**Цель**: Добавить диалоговое добавление RSS-ленты с обязательными ссылкой и названием.
Команда /add запускает диалог: бот сначала просит ссылку, проверяет RSS-ленту, затем просит название и сохраняет ленту. Диалог хранится отдельно для каждого пользователя.
Команда /list показывает название и ссылку каждой ленты.
Команды /latest <название> и /remove <название> находят ленту по заданному пользователем названию.
Команда /cancel отменяет добавление.
**База данных**: Данные пользователей (ленты с названиями, размер страницы, позиция в ленте, состояние диалога) хранятся в базе данных и не пропадают после перезапуска бота. Для этого пишется новая реализация интерфейса хранилища, а логика бота не меняется. Тесты хранилища работают на базе данных в оперативной памяти, поэтому не создают файлов и не зависят друг от друга.

### Примеры:

#### Пример 1. Добавление и чтение ленты

П: /add
Б: Пришлите ссылку на RSS-ленту
П: https://habr.com/rss
Б: Лента найдена. Как её назвать?
П: Хабр
Б: Лента «Хабр» добавлена
П: /list
Б: 1. Хабр — https://habr.com/rss
П: /latest Хабр
Б: 1. Заголовок новости — https://habr.com/...
П: /remove Хабр
Б: Лента «Хабр» удалена

#### Пример 2. Ошибка при вводе ссылки

П: /add
Б: Пришлите ссылку на RSS-ленту
П: habr
Б: Не удалось найти рассылку. Пришлите ссылку ещё раз или введите /cancel
П: /cancel
Б: Добавление отменено

#### Пример 3. Диалоги разных пользователей

П1: /add
Б: Пришлите ссылку на RSS-ленту
П2: /list
Б: Подписок пока нет. Добавьте ленту командой /add
П1: https://habr.com/rss
Б: Лента найдена. Как её назвать?
П1: Хабр
Б: Лента «Хабр» добавлена

## Задача 4. Автоматическая рассылка новостей

**Цель:** Бот регулярно проверяет ленты пользователя и присылает новые записи без команды /latest. Каждая новость отправляется пользователю только один раз. Проверка лент работает отдельно от обработки сообщений в телеграмме, а настройки и сведения об отправленных новостях сохраняются в базе данных.

**Пошаговый ввод для всех команд.** Все команды бота, которым нужен ввод, работают одинаково: без параметра команда запускает пошаговый диалог, а с параметром выполняется сразу. Команда /cancel отменяет любой диалог. В этой задаче пошаговый ввод добавляется и к командам из прошлых задач: /latest и /remove без параметра спрашивают название ленты, /pagesize – размер страницы.

**Команда /interval** задаёт, как часто проверять ленты. Без параметра бот спрашивает интервал; его можно указать просто числом в минутах (30) или с единицей измерения: 30s — секунды, 15m — минуты, 2h — часы, 1d — дни. По умолчанию ленты проверяются каждые 30 минут.

**Команда /quiet** задаёт тихие часы, когда бот не отправляет сообщения; новости, появившиеся в это время, приходят после окончания паузы. Команда работает диалогом: бот сначала спрашивает, с какого часа начинать тихие часы, затем – до какого, и сохраняет настройку. Диалог хранится отдельно для каждого пользователя, команда /cancel отменяет настройку. Команда /quiet off отключает тихие часы. По умолчанию тихие часы не настроены.

**Команда /settings** показывает текущие настройки.

У каждого пользователя свои настройки и свой список уже отправленных новостей. При первом включении рассылки бот не присылает все старые записи из ленты.

### Примеры

#### Пример 1. Настройка рассылки по шагам

П: /interval
Б: Как часто проверять ленты? Пришлите интервал, например: 30, 15m, 2h, 1d
П: 30m
Б: Буду проверять ленты каждые 30 минут

П: /settings
Б: Проверка лент: каждые 30 минут. Тихие часы: не настроены

#### Пример 2. Пошаговый ввод работает у всех команд

П: /latest
Б: Новости какой ленты показать?
П: Хабр
Б: 1. Вышла новая версия Java —[ https://habr.com/](https://habr.com/)...

П: /remove
Б: Какую ленту удалить?
П: Хабр
Б: Лента «Хабр» удалена

#### Пример 3. Новая запись

*У пользователя есть подписка «Хабр». Позже в ленте появляется новая запись.*
Б: Новость из ленты «Хабр»: Вышла новая версия Java —[ https://habr.com/](https://habr.com/)...

#### Пример 4. Тихие часы

П: /quiet
Б: С какого часа не присылать новости?
П: 23
Б: До какого часа?
П: 8
Б: Не буду присылать новости с 23:00 до 08:00
*Новая запись появляется ночью. После 08:00 бот присылает её один раз.*

П: /quiet off
Б: Тихие часы отключены
